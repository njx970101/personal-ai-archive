## 模型回退必须经过真实故障请求验证

- 日期：2026-11-05
- 场景：给 DSH/9bot 配置 quickai 到官方 DeepSeek 的自动回退
- 结果：本地网关日志曾显示 quickai 出错后已转到 deepseek-official，但官方调用返回过 401（API key 无效），并发生连接重置/550；因此最终请求仍会失败并让 DSH 报 502
- 可复用经验：同时检查请求入口是否命中网关、fallback 顺序、实际上游响应、认证状态和网络路径；单测通过或健康接口显示 `hasKey=true` 不代表 key 可用
- 注意事项：`hasKey` 只说明读取到了非空凭据；不要记录或提交 key 值。账号登录与 API key 是不同通道
- 来源：9bot/DSH 回退配置排查（2026-11-05）
